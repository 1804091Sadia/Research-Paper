# Literature Collection and Study Extraction Dataset

## Overview

This repository contains the literature collection and structured study extraction dataset prepared for the systematic literature review titled:

**"Efficient Transformer Architectures for Long-Sequence Modeling: A Systematic Review"**

The repository provides a structured record of the research papers identified, screened, and included in the review. It is intended to support transparency, reproducibility, and further research in efficient Transformer architectures for long-sequence modeling.

## Repository Contents

| File | Description |
|---|---|
| `Additional_file_1.xlsx` | Excel spreadsheet containing the collected research papers and structured extraction information. |

## Dataset Description

The spreadsheet documents the literature search and study selection process, including bibliographic information and relevant research characteristics.

The collection covers research on:

- Linear and recurrent attention architectures
- Sparse attention mechanisms
- Memory and retrieval-based approaches
- Key-value (KV) cache optimization
- Token pooling and multiscale architectures
- Hybrid architectures and State Space Models (SSMs)
- Long-sequence benchmarks and evaluation methods

## Literature Selection Summary

The systematic review followed a structured literature identification and screening process.

| Screening stage | Number of records |
|---|---:|
| Records identified | 275 |
| Duplicates removed | 22 |
| Records screened | 253 |
| Full-text articles assessed | 154 |
| Studies included | 62 |

## Data Sources

The literature collection was compiled from academic research sources, including:

- arXiv
- ACM Digital Library
- ScienceDirect
- NeurIPS
- International Conference on Learning Representations (ICLR)
- Association for Computational Linguistics (ACL)
- AAAI

## Intended Use

This dataset is provided to:

- Support the systematic review and its findings.
- Facilitate verification of the included studies.
- Improve transparency in literature selection and data extraction.
- Assist researchers investigating efficient long-context and long-sequence modeling.

## Reproducibility and Availability

The structured extraction table for the 62 included studies is provided as supplementary research material. The dataset is also intended to be archived on Zenodo with a persistent DOI.
